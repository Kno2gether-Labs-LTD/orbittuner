OrbitTuner, design proposal

For owner sign-off before any app UI is built. Galaxy Z Fold6: folded is the phone, unfolded is the tablet.

Palette: phosphor bronze on night indigo

The accent comes from wound guitar strings: copper and phosphor bronze. It sits on the Orbit family's deep indigo, so the app reads as Orbit but owns warmth that Health, Walker, Secure and Server do not use.

Type and spacing

Literata (OFL) for lyrics, song titles and the big tuner note: a screen-reading serif with optical sizes, calm at arm's length. Schibsted Grotesk (OFL) for UI text and chord symbols, bold and copper, so chords never look like lyrics.

  • sheet sizes: phone / tablet portrait / landscape (default; pinch to change)

The tuner: a taut string

A single string is pinned at both ends of a linear cents rule. Off pitch, the string is pulled into a bend at your cents value, deeper the further you are, toward the flat or sharp side. Inside the ±3 cent slot it snaps straight and turns green. Bending a string is how players raise pitch, so the picture matches the hand.
